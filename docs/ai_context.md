# 个性化学习推荐系统 - 项目上下文

## 基本信息
- 项目名称：基于Java的个性化学习推荐系统
- 学生：你的姓名
- 日期：2025年11月
- 当前阶段：完成最小可运行系统

## 技术栈
- 后端：Java 17 + Spring Boot 3 + MyBatis-Plus + MySQL 5.7
- 前端：Vue 3 + Vite + Element Plus + Vue Router
- 认证：JWT Token
- 算法：基于用户的协同过滤（余弦相似度）

## 核心接口
- `POST /api/login` - 用户登录
- `POST /api/course/{id}/rate` - 课程评分
- `GET /api/course/all` - 所有课程列表
- `GET /api/recommend` - 个性化推荐
- `GET /api/course/{id}` - 课程详情
### 前端
- Vue 3 + Vite
- Element Plus
- Vue Router

### 核心算法
- 基于用户的协同过滤
- 余弦相似度计算
- 已实现CosineUtil


## 数据库设计
1. `user`表：用户信息 (id, username, password, role_id, created_at)
2. `course`表：课程信息 (id, name, description, teacher_id, credit, created_at)
3. `user_course_score`表：评分记录 (id, user_id, course_id, score, created_at)
4. `role`表：角色信息 (id, name)


## 推荐算法
- 算法类型：基于用户的协同过滤
- 相似度计算：余弦相似度
- 数据源：user_course_score表的真实评分数据
- 冷启动：新用户暂无推荐（可后续优化为热门课程）
- 个性化：不同用户获得不同的推荐结果
