## 一、核心目标（Why）
为学生提供 **“千人千面”** 的课程推荐，  
提升 **学习完成率** 与 **满意度**，  
同时给教师 **数据反馈** 辅助教学改进。

## 二、技术路线（What）
1. **算法模型**：基于用户的协同过滤（User-Based CF）
2. **相似度度量**：余弦相似度（Cosine Similarity）
3. **推荐生成**：Top-N 加权排序，已学课程过滤
4. **冷启动**：新用户 → 热门课程兜底

## 三、实现步骤（How）
| 步骤         | 输入                          | 输出                                      | 代码入口                             |
| ------------ | ----------------------------- | ----------------------------------------- | ------------------------------------ |
| ① 加载评分   | `List&lt;UserCourseScore&gt;` | `Map&lt;User,Map&lt;Course,Score&gt;&gt;` | `ScoreService.list()`                |
| ② 相似度计算 | 两用户评分向量                | `double[0,1]`                             | `CosineUtil.cosine()`                |
| ③ 找最近邻   | 所有用户                      | `Top-K 相似用户`                          | `RecommendService.findNeighbors()`   |
| ④ 加权排序   | 邻居评分 + 相似度             | `List&lt;Course&gt;` 已学过滤             | `RecommendService.recommend()`       |
| ⑤ 返回前端   | `Top-N 课程 JSON`             | 200 OK                                    | `RecommendController.apiRecommend()` |

## 五、关键公式（面试手写）
余弦相似度：cos(u,v) = Σ(uᵢ·vᵢ) / (√Σuᵢ² · √Σvᵢ²)

```
Top-N 加权分：score(c) = Σ(sim(u,v) · r(v,c)) / Σsim(u,v)
```

### ✅ 当前算法 **已满足“核心闭环”**：

> 收集评分 → 余弦相似度 → 未评分课程被推出来 → Top-N 返回前端

**但未评分课程的“相似度”一开始并不是靠它自己，而是靠“用户相似度”间接传递**——下面一次讲清。

------

### 🔍 未评分课程的相似度来源（面试常问）

#### ① 不是课程 vs 课程，而是 **用户 vs 用户**

- 我们计算的是 **“用户-用户”余弦相似度**（基于共同评分课程）
- 找到 **Top-K 最相似用户** → 他们评分过的课程 → 作为候选池

#### ② 未评分课程的“分值”是 **加权平均**

公式：

```
score(c) = Σ(sim(u,v) × r(v,c)) / Σsim(u,v)
```

- **r(v,c)**：邻居用户 v 对课程 c 的评分
- **sim(u,v)**：目标用户 u 与邻居 v 的相似度（已算好）
- **分母**：归一化，避免“相似用户越多分值越高”

#### ③ 冷启动兜底（你已做）

- 新用户 / 无邻居 → 直接返回 **热门课程**（点击率 Top-N）
- 热门列表也可缓存到 Redis，10 min TTL

### ✅ 用你今天数据举例

表格

| 步骤          | 输入                       | 输出                                            |
| ------------- | -------------------------- | ----------------------------------------------- |
| 1. 加载评分   | 200 条 (user,course,score) | 用户 1 评分：[1→5, 2→4, 3→4]                    |
| 2. 算用户相似 | 用户 1 vs 用户 2           | sim=0.82                                        |
| 3. 找邻居     | Top-3 相似用户             | [用户2(0.82), 用户3(0.75), 用户4(0.63)]         |
| 4. 加权平均   | 邻居对课程 4 评分          | 用户2:5, 用户3:0 → score(4)=0.82×5 / 0.82 = 5.0 |
| 5. 返回前端   | Top-3 未学课程             | [4, 21, 12]（已过滤已学）                       |

------

### ✅ 一句话答面试

> “未评分课程本身没有向量，我们**用目标用户与邻居的相似度作为权重**，对邻居在该课程的评分做**加权平均**，从而间接得到未评分课程的预测分。
